## Installation

Each skill has its own `install.sh`:

```bash
./solana-dev/install.sh          # personal install (~/.clawd/skills/)
./solana-dev/install.sh --project # project install (.clawd/skills/)
```

Full installation instructions are in the [root README](../README.md).
