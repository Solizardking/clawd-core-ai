# `character/`

Reserved location for Clawd Code's persona/character asset files (avatar art, voice profile config, character-card exports, etc.), analogous to the `character` field pattern used by agent-catalog frameworks.

**Currently empty.** The persona itself is defined in text form at the repository root:

| File | Role |
|---|---|
| [`../SOUL.md`](../SOUL.md) | Manifesto — values, the Six Laws, operating principles per mode |
| [`../IDENTITY.md`](../IDENTITY.md) | Catalog entry — on-chain identity, trust gates, modes, environment |
| [`../clawd.json`](../clawd.json) | Structured bio/lore/message-examples used for agent-catalog registration |

Drop generated avatars, voice presets (for the `sherpa-onnx`/`sag` voice pipeline), or exported character cards here as they're produced.
